Class GmodStyle

Shared "gmod menu" visual style: dark slate panels, a blue accent, and flat buttons with a hover swap and an accent-tinted selected state. Applied per-instance via Robust.Client.UserInterface.Controls.ContainerButton.StyleBoxOverride / Robust.Client.UserInterface.Controls.PanelContainer.PanelOverride so it never touches the global stylesheet or the rest of the game's UI. Used by the improved construction editor and entity selector so they match the improved construction menu.
