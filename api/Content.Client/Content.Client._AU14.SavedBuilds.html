Namespace Content.Client._AU14.SavedBuilds

Classes

BuildPartnerClientSystem

Client side of build partners. Opens the BuildPartnerWindow from the construction menu's "Partners" button, asks the server for the online-player list, and relays grant/revoke toggles back. The server (BuildPartnerSystem) is authoritative and round-scopes the grants.

BuildPartnerWindow

Build-partner management window (opened from the construction menu's "Partners" button). Lists the other online players; for each you can grant or revoke permission for THEM to include YOUR built entities in their saved builds. Fires OnSetPartner; the owning client system relays it to the server.

BuildPlaceOverlay

Placement preview for a saved build: a translucent ghost of each entity's sprite plus the footprint outline (world space, anchored to the cursor / snapped tile), and a small controls hint in the top-left (screen space). Reads its state from SavedBuildPlacementSystem.

BuildSaveCommand

Opens (or closes) the saved-build selection panel and enters selection mode. Bindable to a key.

BuildSaveModeSystem

Client driver for the saved-build selection flow. Tracks the current range, committed range boxes and manual picks, owns the BuildSaveOverlay, periodically asks the server to resolve the selection (so highlights respect the server-only whitelist), and sends the save request.

BuildSaveOverlay

World-space overlay for the saved-build selection: draws the live range box around the player, any committed range boxes, and a translucent fill over every entity the server has confirmed is saveable (resolved from the soft-whitelist). Reads its state from BuildSaveModeSystem.

BuildSaveWindow

Small control panel for the saved-build selection: a range slider (1x1 .. 11x11), append/clear of range boxes, a live count of highlighted (whitelisted) entities, and a name + save. Drives BuildSaveModeSystem; the in-world overlay shows the actual selection.

SavedBuildListSystem

LOCAL storage of saved builds. Builds are private files in this client's own user-data folder (saved_builds/): the server never stores or lists them, so no other player can see them. Sharing is manual - players copy .build.yml files between their folders. The server only produces the file content on save (SavedBuildDataEvent) and consumes it again on placement.

SavedBuildPlacementSystem

SavedBuildThumbnail

A tiny composite preview of a saved build: draws each stored entity's icon at its relative position, scaled to fit a fixed square. Gives the "Saved Builds" cards a real picture of the build instead of just a count.
