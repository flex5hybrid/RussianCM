Class SavedBuildListSystem

LOCAL storage of saved builds. Builds are private files in this client's own user-data folder (saved_builds/): the server never stores or lists them, so no other player can see them. Sharing is manual - players copy .build.yml files between their folders. The server only produces the file content on save (SavedBuildDataEvent) and consumes it again on placement.
