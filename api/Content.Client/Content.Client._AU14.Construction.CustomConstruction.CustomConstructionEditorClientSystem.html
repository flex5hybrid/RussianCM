Class CustomConstructionEditorClientSystem

Client side of the construction-menu editor. Opens ConstructionEditorWindow when the server requests it (after a permitted admin uses a world verb) and relays the confirmed result back to the server. Also drives the in-menu "Construction Items Editor" utility: opens the entity selector, then asks the server to open the editor for the chosen entity (with a client-side admin pre-check).
