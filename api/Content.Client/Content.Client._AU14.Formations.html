Namespace Content.Client._AU14.Formations

Classes

FormationClientSystem

Client-side system managing formation dot placement mode. Holds a reference to the active BUI so the hijack can send placement messages, and updates the ghost facing direction to follow the local player each frame.

FormationDotVisualsSystem

Updates the formation dot sprite each frame:

  • Applies the leader's color tint to the dotArrow layer.
  • Fades alpha linearly from full to zero as DeathTime approaches. Skips entities where MaxLifetime is zero — those are client-side placement ghost previews that manage their own color via the YAML sprite definition.

FormationPlacementHijack

Intercepts left-clicks during formation dot placement. The ghost preview entity (AU14FormationDotGhostFollower/Leader) is rendered by the placement manager using its sprite definition directly — we do not override CurrentTextures so the tinted arrow ghost shows naturally. Press R to rotate the ghost arrow (sets intended facing direction), then left-click to confirm a dot at that tile.
