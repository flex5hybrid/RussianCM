Class InsurgencyBuiltinFactions

Built-in factions that ship with the game rather than being authored in the editor or the DB. Right now that is just the vanilla CLF: the plain Colonial Liberation Front, compatible with every GOVFOR faction and stocked with exactly the equipment the original CLF cell kit deployed.

Kept in code (not the DB) so it is always present and never needs seeding. The selection popup offers it above the DB Default factions, and picking it applies this definition directly. The editor also lists it: because its vendor arsenals are real CMVendorSection data (not baked into a prototype), a host can open it, tweak any item, and save the result as a new Default faction.
