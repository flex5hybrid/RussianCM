Class StructuralSupportComponent

First building block of the z-level structural-stability feature. Marks a structure that participates in the support graph: a tile is "supported" if it can trace a path back to an anchor (ground/bedrock) - either directly, or by cantilevering out from a vertical support within CantileverSpan tiles. The upcoming ZLevelSupportSystem recomputes Supported on build/destroy and schedules a collapse (with an 8s warning) for anything that loses its path to an anchor.

Remarks

Per-material spans (wood < metal < plasteel) are expressed by setting CantileverSpan on each buildable structure's prototype. IsAnchor roots the graph (the ground layer).
