Class AU14NetSpliceInProgressComponent

Live state of one splice attempt, sitting on the mast being worked. It holds the hidden carrier positions, so it is server-only and never networked: the client is not supposed to know where they are. The mast throws sparks for as long as this is on it, which is the window a passing marine has to notice the job.
