Class RMCDeployableComponent

Allows an entity to be deployed into multiple child entities (setups), supports area checks, redeployment, and collapsing back into the original entity. Used for deployable objects like tents, fortifications, etc. Handles all logic for area validation, tool requirements, and storage of the original entity during deployment.
