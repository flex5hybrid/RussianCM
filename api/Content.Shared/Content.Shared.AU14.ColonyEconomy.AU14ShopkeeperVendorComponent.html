Class AU14ShopkeeperVendorComponent

Marks an entity as a player-operated cash vendor. Authorized staff (shopkeep / food service worker) use items on the machine to add stock, then set names and prices via the Manage UI. Regular players insert cash and buy listed items through the Shop UI.
