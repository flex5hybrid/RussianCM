Classes

EditorFactionEntry

InsurgencyExportSheetMessage

Client asks the server to build a ready-to-fill faction spreadsheet (.xlsx bytes). The server bakes every valid entity/icon/job/flag/platoon (by localized name) into the workbook's dropdowns and embeds the field help, then replies with InsurgencyExportSheetResultMessage. When FactionId is set, the sheet is pre-filled with that stored faction's data so a host can round-trip an existing faction; when null it is a blank template to hand to a player.

InsurgencyExportSheetResultMessage

Server's reply carrying the generated workbook as raw .xlsx bytes plus a suggested file name. The client writes it to disk via a save dialog. No macros, so the player who receives it just fills the dropdowns and sends it back - nothing to enable or install.

InsurgencyFactionDeleteMessage

InsurgencyFactionEditorEuiState

State pushed to the faction editor client. Carries every stored faction as a full FactionDefinition (already NetSerializable) plus the round's current GOVFOR platoon id so the editor can hint which factions currently match.

InsurgencyFactionRefreshMessage

InsurgencyFactionSaveMessage

Create (Id null) or update (Id set) a faction. The server revalidates and clamps the definition before storing; client-sent values are never trusted as-is.

InsurgencyFactionSelectMessage

Apply a stored faction for the current round. Server revalidates GOVFOR matching.

InsurgencyImportSheetMessage

Client uploads a filled-in faction spreadsheet (.xlsx bytes) to be imported. The server reads the known sheets into a FactionDefinition and runs it through the same validator every untrusted payload passes (caps + unknown-prototype stripping), so nothing in the file is trusted as-is. Only the cell values are ever read; no formulas or macros are executed.

InsurgencyEditorScope

The two faction-editor entry points. Default is the host-flag INSFOR editor over host-authored factions; Custom is the separate editor (own console command, own authorization gate) over player-authored Custom factions only.
