HescoFillableComponent

Marks a HESCO under construction that can be packed with dirt using an entrenching tool. Every completed fill tick adds ProgressPerTick to the shared Progress regardless of which player performed it, so several marines filling it at once complete it faster. Once Progress reaches Required the entity is replaced by NextStage.
