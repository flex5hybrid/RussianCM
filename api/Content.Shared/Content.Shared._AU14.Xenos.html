ResinFloorPatchComponent

A resin floor the hive can spin across a hole left by a cave-in.

The tile underneath matters more than it looks: an anchored entity cannot exist on an empty tile at all (AddToSnapGridCell refuses one), so a resin patch over a collapsed floor has to LAY a tile before it can anchor itself there. It puts Tile down on spawn and, if it was the one that placed it, tears it back out when destroyed - so cutting the resin reopens the hole rather than leaving free floor behind.

XenoOpenSpaceConstructionComponent

Marks a xeno structure as one that is built into a HOLE rather than onto a floor.

Normal xeno construction demands weeds and a solid, unblocked tile. A structure carrying this wants the exact opposite: an empty tile, weeds or no weeds, because its whole purpose is patching a gap the floor used to occupy. SharedXenoConstructionSystem.CanSecreteOnTilePopup inverts both checks when it sees this component on the build choice.
