Class FactionDefinition

The single serializable shape that drives the whole INSFOR faction featureset. Editors produce one of these, and the round-start apply pipeline consumes one. Contains only data, never executable content, so it is safe to send over the wire from a client-authored Custom faction file. The server always revalidates and recomputes balance values from its own tables before trusting anything here.
