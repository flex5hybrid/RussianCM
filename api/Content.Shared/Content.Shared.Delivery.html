Namespace Content.Shared.Delivery

Classes

DeliveryBombComponent

Component given to deliveries. This delivery will "prime" based on circumstances defined in the datafield. When primed, it will attempt to explode every few seconds, with the chance increasing each time it fails to do so.

DeliveryComponent

Component given to deliveries. Means the entity is a delivery, which upon opening will grant a reward to cargo.

DeliveryFragileComponent

Component given to deliveries. Allows the delivery to be broken. If intact, applies a small multiplier, otherwise substracts it.

DeliveryModifierSystem

System responsible for managing multipliers and logic for different delivery modifiers.

DeliveryPriorityComponent

Component given to deliveries. Applies a duration before which the delivery must be delivered. If successful, adds a small multiplier, otherwise removes a small multiplier.

DeliveryRandomMultiplierComponent

Component given to deliveries. Applies a random multiplier to the delivery on init. Added additively to the total multiplier.

DeliverySpawnerComponent

Used to mark entities that are valid for spawning deliveries on. If this requires power, it needs to be powered to count as a valid spawner.

PrimedDeliveryBombComponent

Component given to deliveries. Indicates this bomb delivery is primed.

SharedDeliverySystem

Shared side of the DeliverySystem. This covers for letters/packages, as well as spawning a reward for the player upon opening.
