ClearBuildPartnersEvent

Client -> server: revoke ALL of my build partners at once. Replies with a fresh list.

PlayerBuiltComponent

Stamped on any entity a player constructs. Doubles as:

  • an accountability/logging mark (the builder's hidden user id),
  • an examine line showing the builder's character name, and
  • the "soft-whitelist" used by the saved-builds feature: only entities carrying this component (built by the saver, or by someone who added the saver as a build partner) may be captured into a saved build.

Server-authoritative: this component is never networked, so BuilderUserId stays hidden from clients. The examine line is pushed by the server.

RequestBuildPartnerListEvent

Client -> server: send me the list of online players and whether each is currently my partner.

RequestBuildSelectionEvent

Client -> server: resolve this selection and send back the highlight set.

RequestPlaceBuildEvent

Client -> server: place a saved build at Target, rotated by Rotation radians. The build file lives on the CLIENT, so the client uploads its YAML here; the server re-validates the caller's admin flags (Spawn/Mapping) and size caps before loading anything from it.

RequestSaveBuildEvent

Client -> server: save the resolved selection under Name.

SavedBuildDataEvent

Server -> client (requester ONLY): the serialized build produced by a save request. The CLIENT writes this to its own local user-data folder - saved builds are private local files, never stored on or listed by the server, and shared by players copying files between their folders themselves.

SetBuildPartnerEvent

Client -> server: grant (Add true) or revoke a player's access to my builds.

BuildPartnerInfo

BuildPreviewEntity

One entity in a build's placement preview: prototype + position relative to the anchor.

BuildPreviewTile

One tile in a saved build's placement preview: tile id + position relative to the anchor.

BuildSelectionBox

A square tile-range box used to select build entities. Radius is the half-extent in tiles, so a radius of 2 selects a 5x5 area centred on Center (max 5 => 11x11).

BuildSelectionData

Describes a build selection: the union of any number of range boxes, plus entities the player manually clicked to include or exclude. The server is authoritative — it resolves this descriptor against the soft-whitelist (PlayerBuiltComponent + build-partner grants) to produce the actual entity set, both for highlighting and for saving.

BuildSelectionTile

One selected grid tile, used by mapper-mode tile saving.

SavedBuildInfo

Metadata for one saved build, shown in the "Saved Builds" construction-menu spawnlist.

Enums

BuildSaveMode

Which selection/placement ruleset a saved-build action runs under. The server re-validates the caller's admin flags for any privileged mode, so a client asking for a mode it isn't authorized for is rejected.
