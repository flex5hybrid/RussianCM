Class EntityIdConstructionGraphStep

A construction step that requires a held/nearby entity matching a specific entity prototype id, regardless of its components (so it works for ANY item — food, seeds, etc. — not just stacks or tagged items). Written by the AU14 in-game construction editor for "custom material" / "custom tool" steps via the entityId: YAML key.

When Consume is true (custom material) the matched entity is consumed into the build, like a normal material insert. When false (custom tool) the entity must merely be present and is NOT consumed — see the handling in ConstructionSystem.Construct.

GenerateGuideEntry()

Generates a guide ("Steps") entry from the target entity's own display name. The base arbitrary-insert step expects a localized Name and feeds it through {LOC($name)}; the in-game editor emits these steps with no Name, and an empty value broke the entire steps list. Resolving the entity name here (and using a plain-text loc string) keeps multi-step / custom recipes showing their steps correctly.
