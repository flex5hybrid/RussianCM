Class BuildPartnerSystem

Tracks round-scoped, one-directional "build partner" grants. If owner O adds player P as a partner, then P is allowed to include O's player-built entities in P's saved builds. Grants are intentionally not persisted across rounds (the entities they refer to are not either) and are cleared on round restart.
