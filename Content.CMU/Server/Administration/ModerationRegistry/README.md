# Закрытый реестр модерации

Создайте текстовый канал Discord с выключенным правом **Просмотр канала** для `@everyone`
и выдайте доступ ролям модерации. Создайте входящий webhook в этом канале.
Передайте его URL серверу через секрет окружения `ROBUST_CVAR_discord__cmu_moderation_webhook`
или задайте `discord.cmu_moderation_webhook` в закрытом серверном конфиге.
Пустое значение отключает сбор и доставку.

После включения реестр публикует новые серверные, ролевые и чатовые блокировки,
административные сообщения игроку и видимые игроку заметки. Карточка фиксирует санкцию на
момент её выдачи. Скрытые заметки, список наблюдения, правки и снятие блокировок
за пределами этого журнала. Пустой список аккаунтов в карточке означает блокировку
по сетевым или аппаратным признакам. Эти признаки из структурированных данных
блокировки не передаются. Свободный текст причины отправляется в карточку, поэтому
сетевые и аппаратные идентификаторы следует оставлять в соответствующих полях панели.

Запись в очереди сохраняется вместе с санкцией в SQLite или PostgreSQL и удаляется
после подтверждения Discord. При временном сбое отправка повторяется.
Если Discord принял запрос и ответ потерялся, повтор может создать вторую карточку
с тем же идентификатором в подвале. Очередь привязана к ID webhook. Если webhook
заменить новым, его очередь начнёт заполняться отдельно, а накопленные записи
останутся в БД с исходным ID. Перед заменой рекомендуется дождаться доставки.
